# Go 标准库安全更新方案

状态：用户已明确允许修改下列 7 个目录外文件，补丁现已应用到工程原文件。原有其他改动保留，尚未提交、推送或部署。

## 原因

- 漏洞：[GO-2026-6859 / CVE-2026-97054](https://pkg.go.dev/vuln/GO-2026-6859)。
- [Go 官方漏洞记录](https://vuln.go.dev/ID/GO-2026-6859.json)指出，HTTP/1 服务使用 MaxBytesReader/MaxBytesHandler 时，请求体超限触发的响应头设置可能与处理器的响应头访问竞争，特定并发条件下会导致服务进程崩溃。
- 当前项目要求 Go 1.27.3；官方修复版本为 Go 1.27.4（较旧分支修复于 1.26.11）。
- 原 GitHub 安全扫描运行已无法读取。本地按 Go 1.27.3 的漏洞版本条件扫描，复现了该漏洞以及截图中的 `UpdateSessionWindow → http.Header.Get`、`FetchCodexModelsManifest → http.Header.Set` 调用链。

## 补丁

文件：[go-1.27.4-security.patch](./go-1.27.4-security.patch)。只更新版本号，不修改后端业务逻辑、不关闭或跳过安全检查。
