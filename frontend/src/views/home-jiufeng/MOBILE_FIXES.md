# Jiufeng 移动端修复与验证

日期：2026-09-19。修改范围：`frontend/src/views/home-jiufeng/`。

## 修复内容

| 页面 | 修复结果 |
| --- | --- |
| 订阅管理 | 手机端搜索独占一行，状态、分组、平台三列同排，操作按钮单独排列 |
| 兑换码管理 | 搜索整行、类型与状态两列、操作按钮两列排列；长兑换码可以换行，复制按钮不再挤出卡片 |
| 风控中心 | 页面网格允许收缩，卡片适应屏幕，审核记录表格在自身区域横向滚动 |
| 系统设置 | 卡片和表单适应屏幕，标签栏横向滚动；支付设置中的取消订单限流控件可换行 |
| 渠道状态 | V1/V2 页面约束内容宽度；V2 筛选栏、监控矩阵、模型表格的横向滚动可用 |
| 登录条款 | 提示和详情弹窗均居中，按可用视口高度限制尺寸；长内容内部滚动，底部按钮保持可见；自动聚焦不触发页面滚动 |
| 登录卡片 | 修复英文桌面位移规则覆盖手机样式的问题，窄屏及平板左右间距一致 |

共同根因之一是页面容器使用隐式网格列，其最小宽度被宽表格和标签栏撑大，随后被外层裁切。现在使用 `minmax(0, 1fr)` 和必要的 `min-width: 0`，让横向滚动发生在具体的表格或标签栏内。设置页保留桌面最大宽度。

- 系统设置的九个标签均在 320 像素下检查；风控和渠道状态使用包含记录的模拟数据检查。
- 用模拟触摸滑动验证设置标签栏、风控表格、渠道状态筛选栏、矩阵和模型表格，均能横向移动；宽内容也能滚到最右端。
- 条款提示和长文档在 320×568、640×360 等尺寸下居中且不越界，按钮可见，长内容可内部滚动。
- `vue-tsc --noEmit` 通过。
- Jiufeng 25 个测试文件、164 项测试通过。
- Vite 生产构建通过；现有依赖和分包体积提示不影响构建成功。
- 对目录外 3994 个 Git 可见文件校验内容指纹，与本轮开始时一致。
