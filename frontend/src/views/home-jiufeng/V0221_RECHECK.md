## 复查范围与结论

沿实际路由及导入关系追踪 130 个 jiufeng 源文件，并对 113 组官方/jiufeng 文件进行对应比较。比较包括脚本逻辑、表单字段、显示条件、事件、组件替换和共享组件引用，排除文案、格式及布局重组造成的差异。

| 范围 | 复查结论 |
| --- | --- |
| 登录、注册、邮箱验证、密码重置、OAuth 回调 | 验证码、Passkey、TOTP、第三方登录、注册开关、邮箱策略、邀请码、返佣码和协议确认流程均有对应实现 |
| 管理员账号、分组、渠道、系统设置 | 本轮未再确认缺失；上一轮价格精度、12h 缓存价、刷新状态及保存栏修复保留 |
| 用户密钥、用量、充值、兑换、订阅 | 列表与统计分离加载、导出、计费明细及相关操作保留；兑换结果改用汇总数组呈现，字段未丢失 |
| 个人资料、模型广场、统计卡片 | 部分界面自行重排，头像/身份绑定/Passkey/TOTP/通知及模型和用量展示能力保留 |
| 运营监控、公告、支付管理、插件、风险控制及审计 | 对应页面及操作保留；风险控制/提示词审计菜单拆分属于导航重组 |
| 路由、功能开关及简易模式 | 简易模式分组通过仪表盘查询参数承载；MCP 通过 jiufeng 动态路由适配接入，不属于入口缺失 |
| 共享组件与工具函数 | 新模型预设、OpenCode 配置、强制刷新、退款错误码、模型广场及可用渠道 12h 计价等沿用升级后的官方实现 |

除按用户要求不启用的引导功能外，本轮未发现其他可确认的前端功能缺失。这是对当前代码与可执行测试的结论，不代表已覆盖所有真实后端数据组合。
